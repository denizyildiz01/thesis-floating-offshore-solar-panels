# WEC-Sim model files.





Before running WEC-Sim run BEMIO\_transfer.m to transfer the Capytaine hydrodynamic data to .h5 format



inside Mooring\\lines.txt configure mooring configuration



wecSimInputFile.m initializes the WEC-Sim simulation



To run type in the command = wecSim



this will run WEC-Sim for the current simulation



For post-processing run outputFile.m



Output is shown in ResultsOutput



During WEC-Sim simulations it is also optional to export a visualisatio in .mp4 or .gif format
